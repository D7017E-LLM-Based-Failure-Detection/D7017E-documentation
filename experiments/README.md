# Experiments and measurements

Anything with numbers goes here: a latency measurement, a model training run, a
load test of the storage layer, an evaluation pass of the reasoning loop. Prose in
`groups/` links here instead of repeating results.

Naming: `YYYY-MM-DD-slug.md` (`2026-10-02-belt-vibration-sampling-rate.md`).
Template: [templates/experiment.md](../templates/experiment.md).

Rules: write the hypothesis *before* running it · record the exact setup including
versions and commit hashes · keep raw data with the experiment (`data/` next to the
file, or a path to it if too large) · a failed experiment is still documented.
