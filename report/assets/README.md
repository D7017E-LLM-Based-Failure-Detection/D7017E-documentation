# Assets

Images, photos and diagram sources.

- `diagrams/` — architecture and dataflow diagrams. **Commit the editable source**
  (`.drawio`, `.svg`, `.puml`, `.mmd`) next to the exported `.png`/`.svg`; a PNG
  alone cannot be updated by the next person.
- Photos of the lab setup: descriptive filenames, date in the name
  (`2026-10-02-conveyor-sensor-mounting.jpg`).

Figures meant for the final report go in [../figures/](../figures) — see
[../outline.md](../outline.md).
