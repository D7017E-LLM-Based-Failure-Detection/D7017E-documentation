Project Subsystems

G1

Testbed, Telemetry & tinyML

Operates the lab conveyor belt, collects high-frequency sensor telemetry, handles signal preprocessing, and deploys compact machine learning models onto microcontrollers following IEC 61499 industrial standards.

Interface: Physical process & sensors Read docs →
G2

LLM ↔ Knowledge Graph

Constructs and maintains RDF ontologies for system semantics, implementing explainable reasoning loops combining SPARQL/SHACL validation with LLMs to diagnose failure modes and generate actionable explanations.

Interface: RDF Ontologies & Reasoning Read docs →
G3

iCAP Platform & Web UI

The SCADA-like operational platform providing scalable time-series telemetry storage, interactive web dashboards, visualization widgets, and hosting the knowledge graph reasoning services and edge ML interfaces.
