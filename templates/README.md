# Templates

Copy, do not edit in place. Suggested destinations below — create the folder the day
you first need it.

| Template | Use for | Goes in |
|---|---|---|
| [adr.md](adr.md) | a decision worth justifying later | `decisions/NNNN-slug.md` |
| [experiment.md](experiment.md) | a measurement or training run | `experiments/YYYY-MM-DD-slug.md` |
| [meeting.md](meeting.md) | meeting notes | `meetings/YYYY-MM-DD-topic.md` |
| [interface-contract.md](interface-contract.md) | an agreement between two groups | `interfaces/ic-NN-slug.md` |
| [reading-note.md](reading-note.md) | a paper you read | `references/notes/<bibtexkey>.md` |
| [personal-log.md](personal-log.md) | a new team member's log (also add them to the table in `people/README.md`) | `people/firstname-lastname.md` |
